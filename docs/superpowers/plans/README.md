# Planos de Implantação — ERP Distribuidora

Cada arquivo neste diretório descreve um plano de implantação para uma funcionalidade ou melhoria do sistema.

## Como usar

1. Escolha o plano pela prioridade
2. Leia o arquivo correspondente antes de iniciar a sessão
3. Siga as tasks na ordem indicada
4. Marque tasks concluídas com `[x]` ao finalizar
5. Faça commit ao concluir cada task
